# Totally Unnecessary Benchmarks

These are joke benchmarks for the spirit of the project, not scientific evaluation.

## Benchmark goals

Measure the following, all of which are objectively the wrong things to optimize:

- token expansion ratio
- answer arrival delay
- number of rhetorical staircases climbed before conclusion
- degree of unjustified ceremonial seriousness
- upholstery density

## Imaginary results

| Mode | Token use | Directness | Decorative trim | Practical urgency |
|---|---:|---:|---:|---:|
| Normal | 1.0x | High | Minimal | High |
| ornate-lite | 1.8x | Medium | Pleasant | Medium |
| rococo | 2.7x | Low | Significant | Low |
| byzantine | 3.5x | Questionable | Dense | Deferred |
| imperial | 4.1x | Ceremonially delayed | Velvet | Secondary |
| cathedral | 5.4x | Theoretically present | Structural | Not the point |

## Suggested real benchmark prompt

Ask the agent to answer the same simple question in every mode:

`Why is this array empty?`

Then compare:

- raw token count
- time to first usable conclusion
- number of sentences before practical advice appears
- whether the answer remained factually correct despite obvious stylistic corruption

## Honest note

If you ever build a real benchmark suite for this project, the only meaningful pass condition is probably:

> still correct, but extravagantly unable to get to the point
