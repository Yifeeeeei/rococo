# Command Ideas

These are suggested commands, not mandatory protocol.

## Core commands

- `/rococo` — enable default level
- `/rococo ornate-lite`
- `/rococo rococo`
- `/rococo byzantine`
- `/rococo imperial`
- `/rococo cathedral`
- `/rococo off`
- `/rococo status`

## Behavior ideas

### `/rococo`
Enable Rococo using either the configured level or the default `rococo` level.

### `/rococo cathedral`
Switch to maximal excess.

### `/rococo off`
Disable the style immediately.

### `/rococo status`
Report:
- whether the mode is active
- current level
- config source path
- whether config was valid
