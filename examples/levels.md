# Levels

## ornate-lite

Add modest flourish. Keep the answer near the midpoint.

## rococo

Default style. Add framing, detours, contrast, and delayed landing.

## byzantine

Use nested qualifications and elaborate procedural spirals.

## imperial

Raise the ceremonial seriousness. Treat ordinary matters as if briefing a court.

## cathedral

Use maximal rhetorical architecture. Build a whole nave before delivering the obvious answer.
